# 🚀 Labs Docker -- Formation & Pratique

Bienvenue dans ce projet de labs Docker ! Il contient **5 exercices
pratiques**, chacun documenté dans un fichier `.md`. Ces labs sont
conçus pour être réalisés facilement via **GitHub Codespaces**, où
Docker est déjà installé et prêt à l'emploi.

------------------------------------------------------------------------

## 🎯 Objectifs pédagogiques

À travers ces labs, vous apprendrez à :

-   Manipuler les commandes Docker essentielles
-   Construire et exécuter des images
-   Gérer les volumes, réseaux, Dockerfiles
-   Explorer l'écosystème Docker dans des scénarios pratiques

Chaque lab propose des explications, des exemples et des manipulations à
réaliser.

------------------------------------------------------------------------

## 🏁 Comment commencer ?

### 1️⃣ **Forker ce repository**

Cliquez sur **Fork** en haut à droite pour créer votre propre copie du
projet.

------------------------------------------------------------------------

### 2️⃣ **Lancer un Codespace**

Dans votre fork :

1.  Aller dans l'onglet **Code**
2.  Choisir **Codespaces**
3.  Cliquer sur **Create codespace on main**

Votre environnement de travail complet s'ouvrira dans le navigateur.

➡️ **Docker est déjà installé dans le Codespace**, aucune installation
locale n'est nécessaire.

------------------------------------------------------------------------

### 3️⃣ **Ouvrir un lab en mode Preview**

Pour lire un lab confortablement :

-   Dans l'explorateur de fichiers, ouvrir par exemple **TP1.md**
-   Cliquer sur **Open Preview** (icône de petit livre en haut à droite)

Vous verrez le lab rendu proprement en mode documentation.

------------------------------------------------------------------------

### 4️⃣ **Réaliser le lab**

Vous pouvez exécuter directement les commandes Docker dans le terminal
intégré.

Chaque lab inclut les objectifs, les commandes à exécuter et des
explications.
